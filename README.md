# 🛒 Zepto Data Analytics Project

📌 Overview

This project focuses on analyzing Zepto’s grocery delivery dataset to extract meaningful business insights using SQL and Power BI. The goal of this project is to understand customer purchasing behavior, product demand, and revenue patterns through structured data analysis and interactive dashboards.

The project demonstrates an end-to-end data analytics workflow including data cleaning, SQL-based analysis, and business intelligence visualization using Power BI.

Through this project, I am learning practical data analytics skills such as writing analytical SQL queries, transforming raw data into useful insights, and building interactive dashboards for business decision-making.

📂 Dataset

The dataset used in this project contains information related to Zepto grocery orders and product details.

Typical fields in the dataset include:

- Product ID – Unique identifier for each product

- Product Name – Name of the item available on Zepto

- Category – Product category (Snacks, Fruits, Beverages, etc.)

- Price – Price of the product

- Discount – Discount applied to the product

- Rating – Customer rating for the product

- Stock Availability – Indicates whether the item is in stock or out of stock

The dataset was cleaned and structured before performing analysis to ensure accurate results.

⚙️ Tools & Technologies

The following tools were used in this project:

- SQL (PostgreSQL / MySQL / SQL Server) – Data querying and analysis

- Power BI – Dashboard creation and data visualization

- Excel / CSV Dataset – Data source

- GitHub – Project documentation and version control

🔎 Project Workflow / Steps

1️⃣ Data Loading

- Imported the Zepto dataset into the SQL database.

- Created structured tables to store product and order-related information.

2️⃣ Data Cleaning

- Data cleaning was performed to improve the quality of the dataset.

Key steps included:

- Removing duplicate records

- Handling missing values

- Standardizing product names and categories

- Correcting inconsistent data formats

- Verifying price and discount values

This step ensures that the analysis is reliable and accurate.

3️⃣ SQL Data Analysis

- SQL queries were used to analyze the dataset and answer important business questions.

Examples of analysis performed:

- Total number of products available

- Category-wise product distribution

- Average product price by category

- Highest and lowest priced products

- Discount distribution across products

- Product rating analysis

- Availability of in-stock vs out-of-stock products

These SQL queries helped transform raw data into meaningful insights.

4️⃣ Data Preparation for Visualization

After performing SQL analysis:

- Cleaned and structured data was exported

- The dataset was imported into Power BI for visualization

📊 Power BI Dashboard

An interactive Power BI dashboard was created to visually represent key insights from the dataset.

Dashboard Features

📈 KPI Cards

Key metrics displayed at the top of the dashboard:

- Total Products

- Average Product Price

- Average Rating

- Total Categories

These KPIs give a quick summary of the dataset.

📊 Category Analysis

Visualizations used:

- Bar Charts

- Column Charts

Insights shown:

- Number of products per category

- Category-wise average price

- Most popular product categories

This helps identify which categories dominate the inventory.

💰 Pricing Analysis

Charts used:

- Histogram / Column Charts

Insights:

- Distribution of product prices

- Expensive vs affordable product categories

- Pricing patterns across categories

⭐ Product Rating Analysis

Visualizations used:

- Bar charts

- Average rating metrics

Insights:

- Products with the highest ratings

- Categories with better customer satisfaction

📦 Stock Availability

Charts used:

- Pie Chart / Donut Chart

Insights:

- Percentage of products in stock

- Percentage of products out of stock

This helps understand inventory availability.

🎛 Interactive Filters (Slicers)

Power BI slicers were added for:

- Product Category

- Price Range

- Ratings

These filters allow users to explore the data dynamically.

📈 Key Insights / Results

Some insights derived from the analysis include:

- Certain categories contain significantly more products than others.

- Product pricing varies widely across different categories.

- Some high-priced items still maintain strong customer ratings.

- A noticeable portion of products may be out of stock, indicating potential inventory challenges.

- Discounts are applied selectively across product categories.

These insights can help businesses optimize pricing strategies, product availability, and inventory planning.
